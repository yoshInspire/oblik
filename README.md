# Сайт студии «Верста»

Next.js 16 (App Router) + React 19, TypeScript. Сайт-визитка веб-студии с формой сбора заявок.
Весь текст и цены лежат в JSON, страницы собираются из них — правки вносятся в контент, а не в разметку.

## Запуск

```bash
npm install
cp .env.example .env.local   # заполнить перед боем
npm run dev                  # http://localhost:3000
```

Сборка и прод:

```bash
npm run build
npm start
```

## Что где лежит

```
content/                 источник правды по текстам и ценам
  site.json              бренд, контакты, прайс, главная, о студии, форма
  services-build.json    5 услуг разработки с нуля
  services-support.json  6 услуг по существующим проектам
app/                     страницы (App Router)
  page.tsx               главная
  uslugi/[slug]/         11 посадочных, генерируются из content/
  price/ about/ contacts/ privacy/
  actions.ts             серверное действие формы заявок
  sitemap.ts robots.ts   генерируются из того же content/
components/              Chrome (шапка, подвал), Blocks, LeadForm, Reveal
lib/                     content (загрузка), seo (мета и микроразметка), leads (доставка)
docs/                    документы этапов 1–2: семантика, тексты, дизайн-система
scripts/                 build-doc (пересборка документа), check-seo, test-form
```

### Как поменять текст или цену

Правите нужный JSON в `content/` → `npm run build`. Меняются одновременно страница,
карта сайта, микроразметка и документ на ревью (`npm run doc`).

### Как добавить услугу

Добавить объект в `services-build.json` или `services-support.json` по образцу соседних.
Страница, карточка на главной, ссылки в подвале, запись в sitemap.xml и разметка `Service`
появятся сами — руками ничего дописывать не нужно.

## Форма заявок

Серверное действие `app/actions.ts`. Работает и без JavaScript — Next отдаёт форму
с прогрессивным улучшением.

Защита и порядок обработки:

1. **Поле-ловушка** `company`: скрыто от людей, заполняется ботами. Заполнено — боту
   отвечаем как при успехе, но заявка никуда не идёт.
2. **Валидация на сервере**: задача от 10 символов, контакт от 5, обязательное согласие
   на обработку данных. Клиентская проверка обходится за десять секунд, поэтому она не в счёт.
3. **Ограничение частоты**: 5 заявок за 10 минут с одного IP.
4. **Сохранение** в `data/leads.jsonl` — всегда, это последняя линия обороны.
5. **Уведомления** в Telegram и на webhook — параллельно; их сбой не роняет отправку формы.

Каталог `data/` в `.gitignore`: там персональные данные.

## Что доделать перед публикацией

- [ ] **Контакты и реквизиты** в `content/site.json` — сейчас заглушки. ИНН и ОГРН в подвале
      влияют на коммерческие факторы Яндекса, это не формальность.
- [ ] **Домен** в `NEXT_PUBLIC_SITE_URL` — от него зависят canonical, sitemap и Open Graph.
- [ ] **Политика конфиденциальности** — в `app/privacy/page.tsx` лежит заготовка. Её должен
      проверить юрист, а обработку персональных данных нужно зарегистрировать уведомлением
      в Роскомнадзоре.
- [ ] **Аналитика**: Яндекс.Метрика с вебвизором и целями на форму, Google Analytics,
      подтверждение прав в Яндекс.Вебмастере и Search Console.
- [ ] **Ограничение частоты** сейчас живёт в памяти процесса. При запуске в нескольких
      копиях или на serverless счётчик нужно вынести в Redis.
- [ ] **Почтовые уведомления**: сейчас Telegram и webhook. Для писем добавить SMTP-клиент
      или сервис рассылок — намеренно не тянул зависимость, пока не выбран провайдер.
- [ ] **Картинка для соцсетей** (`opengraph-image`) — сейчас ссылки разворачиваются без превью.
- [ ] **Кейсы и отзывы** — разделов нет намеренно. Появятся после первых реальных проектов,
      микроразметка отзывов включается только вместе с настоящими отзывами.

## Проверки

```bash
node scripts/check-seo.mjs    # title, description, H1, canonical, микроразметка на всех страницах
node scripts/test-form.mjs    # форма заявок: валидация, ловушка для ботов, лимит частоты
```

Обе гоняются по запущенному серверу: сначала `npm start`, потом скрипт.

## Решения, которые стоит знать

- **`trailingSlash: true`** — единый формат адресов со слешем. Формат выбирается один раз:
  смена после индексации порождает дубли.
- **Состояние формы вынесено в `lib/lead-state.ts`.** Модуль с `"use server"` может
  экспортировать только асинхронные функции; обычный объект оттуда приезжает на клиент
  пустым и роняет форму при первом рендере.
- **`title: { absolute }` в `lib/seo.ts`** — отключает шаблон из layout. Заголовки заданы
  картой релевантности целиком и уже уложены в 60 символов.
- **Порядок услуг** в `lib/content.ts`: первыми идут услуги по существующим проектам.
  Это не эстетика — они первой волны продвижения и приносят трафик раньше остальных.
